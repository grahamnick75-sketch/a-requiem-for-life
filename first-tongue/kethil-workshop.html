The five recovered Current names

Eshara = esha + ra (expression unrestrained)
Orith = or + ith (seeking that makes)
Saelun = sae + lun (holding one another)
Mereth = mer + eth (memory that endures)
Vaedrin = vae + drin (chosen passage)

GM continuity. These are the five ancient names documented in the full language reference. This is a fictional local supernatural language, not Ramaytush or an Indigenous cultural tradition. Script rendering is letter-for-letter and does not translate English sentences.

Kethil glyph key
